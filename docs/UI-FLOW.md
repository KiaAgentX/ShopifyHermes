# طراحی روند شروع (Onboarding UI) — Hermes Shop v1.2

> این سند نقشه‌ی کامل UI بات است. هر تغییری در پیام‌ها یا دکمه‌ها باید اول اینجا آپدیت شود.

## تصمیم‌های تاییدشده (انتخاب مالک)

| موضوع | انتخاب |
|---|---|
| سبک دکمه‌ها | ترکیبی: منوی Inline + دکمه ثابت «🏠 منو» پایین صفحه |
| لحن /start | گرم + معرفی کوتاه فروشگاه |
| زبان | فقط فارسی |
| کاربر بازگشتی | «خوش برگشتی» + دکمه ادامه گفتگو |
| جواب AI | فقط دکمه‌های پیشنهادی **ثابت و منتخب** (از استخر FAQ) — بدون ردیف منو |
| ایموجی | زیاد در کارت‌ها، حداکثر ۳ تا در جواب‌های AI |
| آیتم‌های منو | سوال، کاتالوگ، درباره، راهنما |

## نقشه‌ی جریان

```
هر پیام اول کاربر (message یا callback)
        │
        ├─ چت دیده‌نشده (first contact) ──────────────┐
        │                                            ▼
        │   /start → ① پیام خوش‌آمد + نصب کیبورد ثابت 🏠
        │            ② کارت منو با ۴ دکمه Inline
        │   متن آزاد → جواب AI + دکمه‌های پیشنهادی ثابت
        │
        └─ چت دیده‌شده (returning)
            /start → کارت «خوش برگشتی» + [ادامه گفتگو] [منوی اصلی]
            /menu یا دکمه 🏠 → کارت منو
            دکمه FAQ → جواب فوری (بدون LLM) + پیشنهادهای بعدی
            متن آزاد → جواب AI + دکمه‌های پیشنهادی ثابت
```

## صفحات (کارت‌ها)

### 1. خوش‌آمد (فقط بار اول، همراه نصب کیبورد ثابت)
```
سلام {نام}! 👋✨

من هرمس هستم؛ فروشنده‌ی فروشگاه Hermes Shop 🛍️
اینجا به‌زودی خونه‌ی محصولات دیجیتال می‌شود:
📕 کتاب HTML · 🧩 اسکیل MD · 🪄 پرامپت JSON · 💻 پک کد

تا باز شدن کاتالوگ من همین‌جام؛ بپرس یا از دکمه‌ها استفاده کن 👇
```
(لیست محصولات از `products.json` ساخته می‌شود — همان تک‌منبع حقیقت.)

### 2. منوی اصلی — `menu:main`
```
خب، از کجا شروع کنیم؟ 😊
```
دکمه‌ها: `[💬 سوال بپرس] [📚 کاتالوگ]` / `[✨ درباره] [🆘 راهنما]`

### 3. کاتالوگ — `menu:catalog`
از `products.json` ساخته می‌شود؛ وضعیت فعلی «به‌زودی»:
```
🛒 کاتالوگ Hermes Shop

کاتالوگ دارد ساخته می‌شود 🚧🔨

اولین موج محصولات:
📕 کتاب HTML — راهنمای گام‌به‌گام ساخت صفحه‌های وب از صفر، مناسب مبتدی‌ها
🧩 اسکیل MD — مهارت‌ها و قالب‌های آماده برای ایجنت‌ها و اتوماسیون
🪄 پرامپت JSON — پکیج پرامپت‌های ساختاریافته برای کار با هوش مصنوعی
💻 پک کد — کدهای آماده‌ی کاربردی برای پروژه‌های واقعی

قیمت‌ها با افتتاح اعلام می‌شوند 💰
تا افتتاح من همه‌جا هستم؛ بپرس و قدم بزن 😄
```
دکمه‌ها: `[🔔 خبرم کن]` / `[🏠 منوی اصلی]`

### 4. درباره — `menu:about`  ·  ### 5. راهنما — `menu:help`
مثل v1.1 + یک خط جدید در راهنما: «⚡ دکمه‌های پیشنهادی، جواب فوری می‌دهند»

### 6. خوش‌برگشتی — `/start` برای چت دیده‌شده
```
خوش برگشتی {نام}! 👋😄
از همان‌جا ادامه بدهیم؟
```
دکمه‌ها: `[💬 ادامه گفتگو] [🏠 منوی اصلی]`

### 7. جواب AI (متن آزاد)
متن جواب (ایمن‌سازی HTML) + **فقط** دکمه‌های پیشنهادی — بدون ردیف «🏠 منو»
(کیبورد ثابت پایین صفحه نقش ناوبری را دارد؛ انبوه شدن دکمه‌ها در چت حل شد).

انتخاب پیشنهادها با `pick_sugs()` کلمه‌کلیدی و قطعی انجام می‌شود؛ مثال:
سوال درباره‌ی HTML → `[کتاب HTML چیه؟] [پیش‌نیاز لازمه؟]` / `[چقدر طول می‌کشه؟]`

### 8. جواب فوری FAQ — `faq:<key>`
دکمه‌های پیشنهادی به LLM نمی‌روند؛ جواب آنی و ساختاریافته (**تیتر بولد + بولت‌ها**)
از `FAQ` در bot.py می‌آید. ۱۱ کلید: when / what / html / md / prompt / code /
prereq / learn / price / start / guide.
پس از نمایش، سوال و جواب به حافظه‌ی گفتگو هم اضافه می‌شود تا مکالمه‌ی پیوسته بماند.

### 9. لیست افتتاح — `notify:catalog`
دکمه‌ی «🔔 خبرم کن» (در کارت کاتالوگ و جواب‌های when/price):
chat_id در `data/waitlist.json` ذخیره می‌شود (بدون تکرار) + toast «🔔 در لیست افتتاح!».
این اولین داده‌ی واقعی مشتریان قبل از لانچ است.

## کامندها (setMyCommands)

| کامند | توضیح |
|---|---|
| `/start` | شروع / خوش‌آمد 🎬 |
| `/menu` | منوی اصلی 🧭 |
| `/help` | راهنما 🆘 |
| `/about` | درباره هرمس ✨ |
| `/reset` | پاک‌کردن حافظه گفتگو 🧹 |

## پایداری (فیکس‌های v1 + v1.2)

1. **جواب دوبار:** در استارت، backlog با `getUpdates?offset=-1` کامل تایید می‌شود
   (هیچ پیام قدیمی پردازش نمی‌شود) + `update_id` آخر در `data/state.json` ذخیره می‌شود.
2. **ستاره‌های markdown:** خروجی LLM با `md_to_html()` ایمن می‌شود (escape کامل، تبدیل
   **bold**/*italic*/`code`/bullets به HTML)؛ اگر تلگرام پارس را رد کرد، نسخه‌ی
   متنی ساده دوباره ارسال می‌شود.
3. **متن خراب (v1.2):** گیت کیفیت `Brain._looks_broken()` — جوابِ خالی، بی‌معنی
   (تکرار کاراکتر)، یا اشتباه‌زبان → پرش خودکار به مدل بعدی؛ اگر همه خراب بودند،
   کم‌ضررترین فرستاده می‌شود (نه خطا).
4. **متن دکمه‌ی بریده/بدون گرامر (v1.2):** لیبل‌ها دیگر از LLM نمی‌آیند؛ از
   `FAQ` ثابت، کوتاه (≤۲۴ کاراکتر) و با «؟» درست.
5. **تاخیر (v1.2):** ترتیب استخر بر اساس لاتنسی واقعی: Coarena (۱.۵-۹s) → numes →
   OpenRouter → 9Router؛ دکمه‌های FAQ بدون LLM جواب می‌دهند؛ typing indicator
   در کل مدت فکرِ مدل فعال است.
6. **هالوسینیشن محصول (v1.2):** فکت‌ها فقط از `products.json` به SYSTEM تزریق
   می‌شوند + قفل پرسونا (اسم ثابت «هرمس») + قفل فکت (ممنوعیت اختراع قیمت/تاریخ).
7. **RTL/LTR (v1.2):** قاعده‌ی SYSTEM: واژه‌ی انگلیسی وسط جمله، پایان جمله با
   نقطه/علامت فارسی.

## ذخیره‌سازی وضعیت

- `data/state.json`: `offset` (آخرین update_id) + `seen` (چت‌های خوش‌آمددیده)
- `data/waitlist.json`: `chat_ids` (لیست علاقه‌مندان افتتاح)
- هر دو روی Railway بعد از هر redeploy خالی می‌شوند — نسخه‌ی دائمی با Postgres (فروشگاه) می‌آید.
- `products.json` (در ریشه‌ی ریپو): تک‌منبع حقیقت محصولات — کامیت می‌شود.
