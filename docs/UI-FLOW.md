# طراحی روند شروع (Onboarding UI) — Hermes Shop v1.1

> این سند نقشه‌ی کامل UI بات است. هر تغییری در پیام‌ها یا دکمه‌ها باید اول اینجا آپدیت شود.

## تصمیم‌های تاییدشده (انتخاب مالک)

| موضوع | انتخاب |
|---|---|
| سبک دکمه‌ها | ترکیبی: منوی Inline + دکمه ثابت «🏠 منو» پایین صفحه |
| لحن /start | گرم + معرفی کوتاه فروشگاه |
| زبان | فقط فارسی |
| کاربر بازگشتی | «خوش برگشتی» + دکمه ادامه گفتگو |
| جواب AI | دکمه [منو] + ۲ دکمه سوال پیشنهادی که خود LLM می‌سازد |
| ایموجی | زیاد (حس بات فان و خودمونی) |
| آیتم‌های منو | سوال، کاتالوگ، درباره، راهنما |

## نقشه‌ی جریان

```
هر پیام اول کاربر (message یا callback)
        │
        ├─ چت دیده‌نشده (first contact) ──────────────┐
        │                                            ▼
        │   /start → ① پیام خوش‌آمد + نصب کیبورد ثابت 🏠
        │            ② کارت منو با ۴ دکمه Inline
        │   متن آزاد → جواب AI + کیبورد ثابت نصب می‌شود
        │
        └─ چت دیده‌شده (returning)
            /start → کارت «خوش برگشتی» + [ادامه گفتگو] [منوی اصلی]
            /menu یا دکمه 🏠 → کارت منو
            متن آزاد → جواب AI + [منو] + سوال‌های پیشنهادی
```

## صفحات (کارت‌ها)

### 1. خوش‌آمد (فقط بار اول، همراه نصب کیبورد ثابت)
```
سلام {نام}! 👋✨

من هرمس هستم؛ فروشنده‌ی فروشگاه Hermes Shop 🛍️
اینجا به‌زودی خونه‌ی محصولات دیجیتال می‌شود:
📕 کتاب HTML · 🧩 اسکیل MD · 🪄 پرامپت JSON · 💻 پک کد

تا باز شدن کاتالوگ من همین‌جام؛ بپرس یا از دکمه‌ها استفاده کن 👇
```

### 2. منوی اصلی — `menu:main`
```
خب، از کجا شروع کنیم؟ 😊
```
دکمه‌ها: `[💬 سوال بپرس] [📚 کاتالوگ]` / `[✨ درباره] [🆘 راهنما]`

### 3. کاتالوگ (placeholder) — `menu:catalog`
```
🛒 کاتالوگ Hermes Shop
کاتالوگ دارد ساخته می‌شود 🚧🔨
اولین موج محصولات:
📕 کتاب‌های HTML — راهنماهای کاربردی
🧩 اسکیل‌های MD — مهارت‌های آماده برای ایجنت‌ها
🪄 پرامپت‌های JSON — جعبه‌ابزار هوش مصنوعی
تا افتتاح من همه‌جا هستم؛ بپرس و قدم بزن 😄
```
دکمه: `[🏠 منوی اصلی]`

### 4. درباره — `menu:about`
```
✨ درباره Hermes Shop
... معرفی + نسخه
```

### 5. راهنما — `menu:help`
```
🆘 راهنما
💬 هر سوال داری همان تایپ کن — جواب می‌دهم
🧭 /menu باز کردن منو
🧹 /reset پاک‌کردن حافظه‌ی گفتگوی این چت
🎬 /start شروع دوباره
📌 دکمه «🏠 منو» پایین صفحه همیشه کنارته
```

### 6. خوش‌برگشتی — `/start` برای چت دیده‌شده
```
خوش برگشتی {نام}! 👋😄
از همان‌جا ادامه بدهیم؟
```
دکمه‌ها: `[💬 ادامه گفتگو] [🏠 منوی اصلی]`

### 7. جواب AI
متن جواب (بدون markdown، ایمن‌سازی HTML) + دکمه‌ها:
```
[🏠 منو]
[سوال پیشنهادی ۱] [سوال پیشنهادی ۲]
```
سوال‌های پیشنهادی از خود LLM می‌آیند: خط آخر جواب باید
`SUGGEST: سوال ۱ | سوال ۲` باشد؛ اگر نیامد، دو سوال پیش‌فرض نمایش داده می‌شود.
دکمه‌ی پیشنهاد = همان متن به‌عنوان پیام کاربر پردازش می‌شود (به حافظه هم اضافه می‌شود).

## کامندها (setMyCommands)

| کامند | توضیح |
|---|---|
| `/start` | شروع / خوش‌آمد 🎬 |
| `/menu` | منوی اصلی 🧭 |
| `/help` | راهنما 🆘 |
| `/about` | درباره هرمس ✨ |
| `/reset` | پاک‌کردن حافظه گفتگو 🧹 |

## پایداری (فیکس باگ‌های v1)

1. **جواب دوبار:** در استارت، backlog با `getUpdates?offset=-1` کامل تایید می‌شود
   (هیچ پیام قدیمی پردازش نمی‌شود) + `update_id` آخر در `data/state.json` ذخیره می‌شود.
2. **ستاره‌های markdown:** خروجی LLM با `md_to_html()` ایمن می‌شود (escape کامل، تبدیل
   **bold**/*italic*/`code`/bullets به HTML)؛ اگر تلگرام پارس را رد کرد، نسخه‌ی
   متنی ساده دوباره ارسال می‌شود.

## ذخیره‌سازی وضعیت

`data/state.json` (فقط حافظه‌ی کوتاه‌مدت؛ روی Railway بعد از هر redeploy خالی می‌شود):
- `offset`: آخرین update_id پردازش‌شده
- `seen`: لیست chat_idهایی که «خوش‌آمد» را دیده‌اند (برای خوش‌برگشتی)

> نسخه‌ی دائمی ذخیره‌سازی با Postgres (فروشگاه) می‌آید.
