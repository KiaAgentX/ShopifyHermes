# Hermes Shop 🤖🛍️

بات فروشنده فروشگاه محصولات دیجیتال — نسخه 1.2

بات تلگرامی که با مغز LLM (سازگار با OpenAI) حرف می‌زنه. نقشه‌ی راه: اتصال به دیتابیس فروشگاه، مشاور فروش (نقش A) و تولیدکننده محصول (نقش B).

## چه چیزهایی در v1.2 حل شد (پک ۱۰ ایراد)

- **متن خراب:** گیت کیفیت در مغز — جواب بی‌معنی/اشتباه‌زبان → پرش خودکار به مدل بعدی
- **تاخیر:** Coarena (سریع‌ترین، ۱.۵-۹ ثانیه) اول استخر + typing indicator در کل مدت فکر
- **دکمه‌های پیشنهادی:** به‌جای لیبل‌های تولیدی LLM (بریده/بی‌گرامر)، استخر FAQ ثابت و منتخب — و دکمه‌های FAQ **جواب فوری** می‌دهند (بدون LLM)
- **هالوسینیشن محصول:** تک‌منبع حقیقت `products.json` — فکت‌ها فقط از آن به SYSTEM تزریق می‌شوند + قفل پرسونا «هرمس»
- **انبوه شدن منو:** ردیف «🏠 منو» از زیر هر جواب حذف شد؛ کیبورد ثابت پایین صفحه نقش ناوبری دارد
- **کارت به‌زودی:** دکمه‌ی «🔔 خبرم کن» + لیست علاقه‌مندان در `data/waitlist.json` (بدون تکرار)
- **ساختار جواب‌ها:** خط اول مستقیم + حداکثر ۳ بولت (قاعده‌ی SYSTEM) + قاعده‌ی RTL برای واژه‌های انگلیسی

## راه‌اندازی

```bash
cp .env.example .env   # مقادیر واقعی را پر کنید
python3 bot.py
```

متغیرهای محیطی روی Railway (Raw Editor): همان کلیدهای `.env` — شامل
`OPENROUTER_API_KEY` + `OPENROUTER_MODELS`، `COARENA_API_KEY` + `COARENA_MODELS`
و `ROUTER9_API_KEY` + `ROUTER9_MODELS` برای تامین‌کننده‌های دوم به بعد.

## معماری ضدخطا (brain)

استخر (pool) از همه ترکیب‌های (تامین‌کننده، کلید، مدل) ساخته می‌شود؛ به ترتیب لاتنسی واقعی:

1. Coarena: مدل‌های `COARENA_MODELS` (سریع‌ترین — ۱.۵-۹s؛ اعتبار رایگان $5 در روز)
2. numes: همه مدل‌های `MODELS` × همه کلیدهای `NUMES_API_KEYS`
3. OpenRouter: مدل‌های `OPENROUTER_MODELS` (فقط مدل‌های `:free`)
4. 9Router: مدل‌های `ROUTER9_MODELS` (پروکسی Railway، مدل‌های `oc/*-free`)

- خطای مدل (502/timeout/جواب خالی) → ورودی بعدی
- خطای کلید (401/402/403/429) → ورودی بعدی (چرخش کلید طبیعی اتفاق می‌افتد)
- **گیت کیفیت (v1.2):** جوابِ خالی، بی‌معنی (تکرار کاراکتر) یا اشتباه‌زبان → ورودی بعدی؛ اگر همه خراب بودند، کم‌ضررترین فرستاده می‌شود
- ترکیب موفق آخر، دفعه بعد اول امتحان می‌شود

> مدل‌های free روی OpenRouter چرخشی هستند؛ با اسکریپت‌های زیر لیست تازه بگیرید:
> `python3 /home/z/my-project/scripts/openrouter_probe.py` (OpenRouter)
> `python3 /home/z/my-project/scripts/coarena_probe.py` (Coarena + تست feedback)
> `python3 /home/z/my-project/scripts/router9_probe.py` (9Router)
