# Hermes Shop 🤖🛍️

بات فروشنده فروشگاه محصولات دیجیتال — نسخه 1

بات تلگرامی که با مغز LLM (سازگار با OpenAI) حرف می‌زنه. نقشه‌ی راه: اتصال به دیتابیس فروشگاه، مشاور فروش (نقش A) و تولیدکننده محصول (نقش B).

## فایل‌ها

| فایل | نقش |
|---|---|
| `bot.py` | حلقه تلگرام (long-polling) + حافظه گفتگو |
| `brain.py` | مغز LLM با failover خودکار مدل‌ها و چرخش کلیدها |
| `send_message.py` | ابزار کوچک ارسال پیام |
| `llm_test.py` | تست سریع API (`list` / `chat`) |
| `model_scan.py` | اسکن همه مدل‌ها: کدام کار می‌کند، کدام پولی، کدام خراب |
| `retry_timeouts.py` | تست مجدد مدل‌های timeout با تایم‌اوت بلند |
| `models_report.csv` | گزارش کامل اسکن |

## راه‌اندازی

```bash
cp .env.example .env   # مقادیر واقعی را پر کنید
pip install -r requirements.txt   # فقط stdlib استفاده شده — این مرحله اختیاری است
python3 bot.py
```

## معماری ضدخطا (brain)

- مدل اول امتحان می‌شود؛ خراب بود (502/timeout) → مدل بعدی
- کلید پر شد (402) یا محدود شد (429) → کلید بعدی (`NUMES_API_KEYS`)
- ترکیب (کلید، مدل) موفق آخر، دفعه بعد اول امتحان می‌شود

## امنیت

- `.env` در `.gitignore` است و هرگز کامیت نمی‌شود
- توکن‌ها را قبل از انتشار عمومی پروژه rotate کنید
